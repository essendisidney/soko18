# Core feature prompts

Once context is set, @ `docs/architecture.md`, `docs/contracts.md`, and `docs/ui-design.md`, then use:

## Backend (REST API & Auth)

Using the architecture and contracts provided, generate the full Node.js/Express backend. Include user registration, login, and JWT authentication. Create the endpoint for swiping logic.

## Frontend (The Swipe Interface)

Based on the ui-design.md, generate the React Native screen for the main swipe feed. The cards should render user data from the API and handle like and pass gestures.

## Real-time Chat

Generate the code for a real-time messaging feature using Socket.io. It should allow users who have mutually liked each other to send and receive messages instantly.

## Safety Features

Create an in-app reporting system and an emergency panic button UI that sends the user’s location to a pre-set emergency contact.

## Anonymity

@ `docs/anonymity.md`. Incognito, hashed contact blocks, 24-hour chats, skip-the-line and mystery as catalog prices. Never invent waitlist density.
